DIVYA DHWANI — INTERACTIVE PROOF OF CONCEPT

FILES
- index.html: a self-contained interactive prototype. No external libraries or image files are required.

OPEN LOCALLY
1. Download and unzip the bundle.
2. Open index.html in Chrome, Safari, Edge or Firefox.
3. Click Explore, choose an age group, open a course and try the activities.
4. Complete each of the seven course sections, answer the knowledge check correctly, then use “Complete course & unlock reward”.
5. Visit My Sanctuary and My Learning to see progress and certificates.

IMPORTANT LIMITATIONS
- This is a front-end proof of concept, not a production LMS.
- No real user accounts, cloud database, admin console, analytics, emails, live videos, or LearnHouse connection are included.
- Progress is saved only in the browser/device where the prototype is opened. Different people opening the hosted page do not share progress.
- Certificates are illustrative and are not official credentials.
- Resident images, family quotes, caretaker details, actual video footage, and several Jain-story references require approval and replacement before public educational use.
- Do not enter children's personal information. This prototype does not collect or transmit information, but production use with children needs privacy and safeguarding review.

PUBLISH A SHAREABLE WEB LINK WITH GITHUB PAGES
1. Sign in to GitHub and create a new repository, for example: divya-dhwani-poc.
2. Upload index.html to the top level of the repository. Keep the file named exactly index.html.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose “Deploy from a branch”.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. The Pages screen will show the live website URL. Share that URL with reviewers.
7. Anyone with the URL can access the demo. Do not publish private material or real children's information.

Official instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

EDITING
- The prototype is a single HTML file. A developer can edit the text in the course data near the top of the <script> section, adjust the visual styles in <style>, or extend the click handlers for more activities.
